# RASTY BEAUTY V2 — ADMIN + DATABASE

## 1. Buat database gratis
Gunakan Supabase dan buat project baru.

## 2. Jalankan database
Buka SQL Editor di Supabase, lalu jalankan `supabase_schema.sql`.

## 3. Buat akun admin
Di Supabase: Authentication > Users > Add user.
Gunakan email dan password khusus admin RASTY BEAUTY.

## 4. Hubungkan website
Buka `js/supabase-config.js`, isi:
- SUPABASE_URL
- SUPABASE_ANON_KEY

Keduanya ada di Supabase: Project Settings > API.

## 5. Jalankan website
Buka `index.html`.

## 6. Admin
Buka `admin.html`.
Login menggunakan akun admin Supabase.

Alur:
Customer checkout
→ data masuk ke tabel orders/order_items
→ admin login
→ admin melihat daftar pesanan
→ admin membuka detail
→ admin mengubah status pesanan.

CATATAN:
Versi ini memakai Supabase free tier untuk tahap awal. Batas penggunaan dan ketentuan layanan dapat berubah, jadi cek dashboard Supabase sebelum dipakai pada skala besar.
